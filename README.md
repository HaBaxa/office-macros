# office-macros

I'll just put here some macros for office applications.
I strive to implement the minimal necessary amount of code so that everyone can quickly understand it and safely apply it themselves.
_For example, in abbrvs.vba I didn't add functionality for creating tables for abbreviations or sorting collections. These are additional features that can be implemented in various ways._

### abbrevs.vba
The script gathers all abbreviations (consisting of two or more capital letters) from the document and places them at the end.
